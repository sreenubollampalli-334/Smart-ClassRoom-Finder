# Smart Classroom Finder

The easiest way to find, book, and manage classroom resources and projectors across the campus.

## Features
- **Student Live Board:** Realtime overview of campus classrooms, their occupancy status, and projector availability.
- **CR Dashboard:** Dedicated portal for Class Representatives to book rooms, request projectors from other classes, and manage their schedule.
- **HOD Dashboard:** Admin control room for the Head of Department to approve CRs, manage the master list of rooms, and oversee all campus bookings.

## Tech Stack
- React + Vite
- Tailwind CSS
- Supabase (PostgreSQL, Auth, Realtime)
- Lucide React (Icons)
